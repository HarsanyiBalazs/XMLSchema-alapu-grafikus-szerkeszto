\noindent \textbf{\Large CD Használati útmutató}

\vskip 1cm
A CD-n a következőek szerepelnek:
\begin{itemize}
\item A szakdolgozat a \texttt{dolgozat.pdf} fájl formájában,
\item a LaTeX forráskódja a dolgozatnak a szakdolgozat mappában,
\item az elkészített program a grafikus\_szerkeszto mappában,
\item az XSD sémák és hozzájuk XML dokumentumok példaként, amikkel a programot lehet tesztelni az xmlpeldak mappában.
\end{itemize}
A program futtatásához a \ref{sec:dependencies}. és a \ref{sec:install}. szekciókban található leírás.
